# Zakupy

Prywatna aplikacja PWA: paragony, własny cennik, budżet i okazje. Dane tylko w telefonie (IndexedDB), bez serwera.
Bez zależności; ES modules. Testy: `node test/unit.mjs`, `python3 test/e2e.py <katalog_zrzutów>` (Playwright).
Repozytorium jest publiczne: nie wolno w nim zapisywać kluczy ani danych osobistych (klucz Gemini wpisuje się tylko w aplikacji).
